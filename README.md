# Тренажёр экзамена на знание Кипра

Сайт: https://andy-with.github.io/cyprus-exam/

Подготовка к экзамену *Εξέταση Πιστοποίησης της Επαρκούς Γνώσης Βασικών Στοιχείων της Σύγχρονης Πολιτικής και Κοινωνικής Πραγματικότητας της Κύπρου*: пробные тесты на греческом, вопросы по карте, перевод на русский, аудио вопросов и рассказы по темам.

## Источники

- Вопросы прошлых сессий восстановлены кандидатами по памяти и опубликованы на mnemospeak.com. Это не официальные тексты.
- Тренировочные наборы — переработанный и проверенный сборник блога DOM (dom.com.cy, 2024).
- Актуальные факты проверены на октябрь 2026 года по официальным сайтам и прессе.
- Карта: контуры — Natural Earth; границы районов — © участники OpenStreetMap (ODbL), через geoBoundaries.
- Озвучка: греческий — Google TTS, русский — Silero.

Официальная информация об экзамене: https://enimerosi.moec.gov.cy/d1/ye
